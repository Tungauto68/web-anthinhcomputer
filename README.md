# An Thịnh Computer – Website

Website giới thiệu dịch vụ của **An Thịnh Computer**: sửa chữa PC, laptop, máy in; IT Helpdesk, IT Outsourcing, quản trị hạ tầng mạng, server và Microsoft 365 cho doanh nghiệp.

Website tĩnh (HTML/CSS/JS thuần), không cần build — chạy trực tiếp trên GitHub Pages.

## Cấu trúc
- `index.html` – nội dung trang
- `styles.css` – giao diện
- `script.js` – menu mobile, hiệu ứng, form liên hệ (mở email)
- `favicon.svg` – biểu tượng

## Cập nhật thông tin liên hệ
Tìm và thay trong `index.html` / `script.js`:
- `0900 000 000` / `0900000000` – hotline & Zalo
